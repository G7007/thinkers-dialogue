# 与思想者对谈 · Thinkers Dialogue

一个以中文对话为主的 AI Skill：根据话题邀请哲学家、社会学家、判断研究者或企业家，以有来源的思想与表达习惯，帮助你检验观点、理解问题和练习表达。

人物以“思想模拟”身份交流。档案、论证方式和来源记录全部可查看、可修改。

## 快速体验

在支持本地 Skills 的 AI 助手中安装后，可以这样开始：

```text
使用 $thinkers-dialogue，让苏格拉底和我讨论：什么才算一份好工作？
先自我介绍，直接回应我的观点，一次推进一个问题。
```

也可以把选人交给 Skill：

```text
使用 $thinkers-dialogue，根据这个问题选一位人物：
我想做自己的作品，但不知道如何判断哪些细节值得投入。
请先介绍自己，再和我讨论。
```

更多例子：

- `请邀请尼采，讨论“成功的标准应该由谁决定”。`
- `让卡尼曼帮我区分：一次选择的结果不好，是否代表当时判断有问题？`
- `邀请韦伯与乔布斯，对照讨论职业中的制度条件与作品价值，给我插话的空间。`
- `回看刚才的对话：我的观点在哪一步发生了变化？有哪些问题仍未解决？`

## 人物库

| 类别 | 人物 | 可讨论的方向 |
| --- | --- | --- |
| 哲学与价值 | 尼采、苏格拉底、庄子 | 评价尺度、概念与理由、视角与自由 |
| 社会与结构 | 韦伯、布迪厄、杜波依斯 | 职业制度、资源与承认、身份与社会评价 |
| 经济与判断 | 亚当·斯密、凯恩斯、卡尼曼 | 激励与公正、不确定性、决策与证据 |
| 企业与创新 | 马斯克、乔布斯、贝索斯 | 工程约束、作品体验、长期投入与可逆决策 |

## 对话如何运转

1. 根据用户指定的人物或本轮问题，读取对应档案。
2. 首次开场标明“姓名｜思想模拟”，说明本题的讨论角度。
3. 提供观点、理由、例证或反例，通常一次推进一个争点。
4. 保持角色和表达方式；用户可以反驳、换人或邀请第二位人物。
5. 按需回看用户实际表达的观点，区分事实、假说与未解决的问题。

对话卡的跨会谈保存需要宿主提供持久存储；本仓库没有自带数据库或记忆服务。

## 安装与使用

这是由 Markdown 指令、人物档案和界面元数据组成的 Skill。运行对话需要能读取这些文件的 AI 助手。

### 本地 Codex 环境

克隆仓库：

```bash
git clone https://github.com/G7007/thinkers-dialogue.git
```

将仓库中的 `thinkers-dialogue/` 整个目录复制到你的 Codex Skills 目录。默认目录通常为 `~/.codex/skills/`；配置了 `CODEX_HOME` 时使用该环境的 Skills 目录。已有同名 Skill 时先检查并备份，再决定是否替换。

让宿主重新发现 Skills 后，以 `$thinkers-dialogue` 或上述中文请求开始。

私有仓库的克隆需要你自己的 GitHub 访问权限。

### 其他 AI 助手

若宿主支持 `SKILL.md` 结构，导入完整的 `thinkers-dialogue/` 文件夹。若只支持普通提示词，提供 [主指令](thinkers-dialogue/SKILL.md) 和本轮所需的人物档案，并要求先读取档案；具体加载方式取决于宿主。

## 来源与边界

每份人物档案区分思想观察、风格归纳和现代推演，并提供公开材料的链接与取样位置。现有取样账目记录十二位人物、六十处片段、二十六个来源 URL；这些数字来自既有档案记录，本次整理没有重新核验全部外部链接。

校准例是原创模拟台词。逐字引文需要另行核对原作与版本；苏格拉底的档案依据柏拉图文本中的人物形象。中文表达可能经过翻译与重建，输出质量也会随模型及上下文变化。

新增人物时，按 [取样与扩充规则](thinkers-dialogue/references/sampling.md) 建立独立档案，并更新人物索引与覆盖账目。
